# 云函数接口说明

云函数均通过 `wx.cloud.callFunction` 调用，使用 `action` 参数区分具体操作。

## login

用于检测云开发链路并获取当前微信用户身份。

请求：

```js
wx.cloud.callFunction({ name: 'login' })
```

返回：

| 字段 | 说明 |
|---|---|
| `openid` | 当前用户 openid |
| `appid` | 小程序 AppID |
| `unionid` | 用户 unionid，未开通时为空 |
| `env` | 当前云环境 |

## postService

社区动态服务。

| action | 参数 | 返回 | 说明 |
|---|---|---|---|
| `list` | 无 | `{ posts }` | 获取帖子列表 |
| `get` | `id` | `{ post }` | 获取帖子详情 |
| `create` | `content`, `resort` | `{ posts }` | 发布动态 |
| `toggleLike` | `id` | `{ posts }` | 点赞或取消点赞 |
| `comment` | `id`, `content` | `{ post }` | 发表评论 |
| `delete` | `id` | `{ posts }` | 删除本人发布或允许删除的动态 |
| `reset` | 无 | `{ posts }` | 恢复默认社区动态 |

## orderService

订单服务。

| action | 参数 | 返回 | 说明 |
|---|---|---|---|
| `list` | 无 | `{ orders }` | 获取当前用户订单 |
| `create` | `type`, `title`, `price`, `status` | `{ orders }` | 创建订单 |
| `reset` | 无 | `{ orders }` | 恢复默认订单 |

## favoriteService

收藏服务。

| action | 参数 | 返回 | 说明 |
|---|---|---|---|
| `list` | 无 | `{ favorites }` | 获取当前用户收藏 |
| `isFavorited` | `targetId` | `{ favorited }` | 判断是否已收藏 |
| `toggle` | `item` | `{ favorited, favorites }` | 收藏或取消收藏 |
| `reset` | 无 | `{ favorites }` | 恢复默认收藏 |

`item` 参数字段：

| 字段 | 说明 |
|---|---|
| `targetId` | 被收藏内容 ID |
| `type` | 收藏类型 |
| `title` | 收藏标题 |
| `desc` | 收藏描述 |

## weatherService

天气服务。当前使用 Open-Meteo 免费天气接口，通过云函数中转请求，前端不直接访问第三方接口。

| action | 参数 | 返回 | 说明 |
|---|---|---|---|
| `current` | `resort` | `{ weather }` | 获取指定雪场实时天气 |

`resort` 参数字段：

| 字段 | 说明 |
|---|---|
| `id` | 雪场 ID |
| `name` | 雪场名称 |
| `location` | 雪场位置 |
| `latitude` | 纬度 |
| `longitude` | 经度 |

`weather` 返回字段：

| 字段 | 说明 |
|---|---|
| `weatherText` | 天气摘要，如晴 9℃ |
| `snowText` | 雪况摘要 |
| `temperature` | 温度 |
| `windSpeed` | 风速 |
| `snowfall` | 当日降雪量 |
| `updatedAtText` | 更新时间 |
| `source` | 数据来源 |
