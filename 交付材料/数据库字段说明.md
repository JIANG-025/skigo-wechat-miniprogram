# 数据库字段说明

本项目使用微信云数据库，当前核心集合为 `posts`、`orders`、`favorites`。雪场、装备、教练等展示数据暂存于 `utils/mock-data.js`，便于小程序前端快速渲染；后续可按相同字段迁移为云数据库集合。

## posts

社区动态集合。

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | String | 云数据库自动生成的记录 ID |
| `_openid` | String | 云开发自动写入的创建者 openid |
| `id` | String | 业务 ID，如 `post-1` |
| `author` | String | 发布者昵称 |
| `initial` | String | 昵称首字或头像兜底字符 |
| `resort` | String | 关联雪场名称 |
| `content` | String | 动态正文 |
| `images` | Array<String> | 图片路径列表 |
| `avatar` | String | 头像图片路径 |
| `likes` | Number | 点赞数量 |
| `likedBy` | Array<String> | 点赞用户 openid 列表 |
| `comments` | Number | 评论数量 |
| `commentsList` | Array<Object> | 评论列表 |
| `deletable` | Boolean | 是否允许当前演示用户删除 |
| `createdAt` | Number | 创建时间戳 |
| `createdAtText` | String | 页面展示用创建时间 |

`commentsList` 子字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 评论业务 ID |
| `author` | String | 评论者 |
| `content` | String | 评论内容 |
| `_openid` | String | 评论者 openid |
| `createdAt` | Number | 评论时间戳 |

## orders

用户订单集合。

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | String | 云数据库自动生成的记录 ID |
| `id` | String | 业务订单 ID |
| `ownerOpenid` | String | 订单所属用户 openid |
| `type` | String | 订单类型，如雪票订单、装备订单、酒店订单、教练订单 |
| `title` | String | 订单标题 |
| `status` | String | 订单状态，如待确认、待使用、已完成 |
| `price` | Number | 订单金额 |
| `createdAt` | Number | 创建时间戳 |
| `createdAtText` | String | 页面展示用创建时间 |

## favorites

用户收藏集合。

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | String | 云数据库自动生成的记录 ID |
| `id` | String | 收藏业务 ID |
| `ownerOpenid` | String | 收藏所属用户 openid |
| `targetId` | String | 被收藏内容业务 ID |
| `type` | String | 收藏类型，如雪场、装备、帖子 |
| `title` | String | 收藏标题 |
| `desc` | String | 收藏描述 |
| `createdAt` | Number | 收藏时间戳 |

## 可扩展集合

后续可将当前静态展示数据迁移为以下集合：

| 集合 | 说明 |
|---|---|
| `resorts` | 雪场信息，经纬度、图片、票价、天气雪况等 |
| `products` | 装备商品信息 |
| `coaches` | 教练信息、资质、课程价格 |
| `hotels` | 酒店信息、价格、设施、关联雪场 |
| `users` | 用户资料、昵称、头像、等级说明 |
