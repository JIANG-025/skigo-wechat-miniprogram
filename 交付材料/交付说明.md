# 交付说明

## 交付内容

- `滑雪小程序源码/`：微信小程序完整源码
- `交付材料/数据库字段说明.md`：云数据库集合与字段说明
- `交付材料/云函数接口说明.md`：云函数接口说明
- `交付材料/交付说明.md`：项目导入、部署和测试步骤
- `项目总览与需求说明.md`、`项目时间线.md`：项目过程与需求记录

## 导入步骤

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `滑雪小程序源码/`。
4. AppID 使用目标小程序 AppID。
5. 导入后确认项目可正常编译。

## 云函数部署

1. 打开微信开发者工具中的云开发面板。
2. 确认云环境为 `cloud1-d6geemhftac318bc0`，或替换为实际交付环境。
3. 在资源管理器中右键 `cloudfunctions/`，选择当前云环境。
4. 依次右键以下云函数并选择“上传并部署：云端安装依赖”：
   - `login`
   - `postService`
   - `orderService`
   - `favoriteService`
   - `weatherService`

## 测试流程

建议按以下顺序测试：

1. 设置与帮助：点击云端连接检测。
2. 首页：测试顶部轮播图点击、天气/雪况切换、天气刷新。
3. 雪场：进入雪场详情，测试收藏和订票。
4. 装备：进入装备详情，测试收藏、购买和租赁。
5. 酒店：进入酒店详情，测试预订订单。
6. 教练：进入教练详情，测试预约订单。
7. 社区：发布动态、点赞、进入详情评论、收藏、删除。
8. 我的：检查订单数量、收藏数量、我的订单、我的收藏。

## 注意事项

- 天气服务当前使用 Open-Meteo，无需 API Key；如果后续换成需要密钥的天气平台，应只在云函数中配置密钥，不写入前端页面。
- `project.private.config.json` 属于本机开发者工具配置，不建议纳入公共仓库。
- 如更换云环境，需要同步修改 `app.js` 中的 `env` 并重新部署云函数。
