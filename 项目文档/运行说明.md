# 运行说明

## 项目内容

- `滑雪小程序源码/`：微信小程序源码
- `项目文档/数据库字段说明.md`：云数据库集合与字段说明
- `项目文档/云函数接口说明.md`：云函数接口说明
- `项目文档/运行说明.md`：项目导入、部署和测试步骤

## 导入步骤

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `滑雪小程序源码/`。
4. AppID 使用目标小程序 AppID。
5. 导入后确认项目可正常编译。

## 云函数部署

1. 打开微信开发者工具中的云开发面板。
2. 确认云环境为 `cloud1-d6geemhftac318bc0`，或替换为实际运行环境。
3. 在资源管理器中右键 `cloudfunctions/`，选择当前云环境。
4. 依次右键以下云函数并选择“上传并部署：云端安装依赖”：
   - `login`
   - `postService`
   - `orderService`
   - `favoriteService`

天气模块直接请求 `https://api.open-meteo.com` 获取实时天气。真机、体验版或正式版测试前，需要在微信公众平台将 `api.open-meteo.com` 添加到 request 合法域名。

## 测试流程

建议按以下顺序测试：

1. 设置与帮助：点击云端连接检测。
2. 首页：测试顶部轮播图点击、天气/雪况切换、天气刷新。
3. 雪场：进入雪场详情，测试收藏和订票。
4. 装备：进入装备详情，测试收藏、购买和租赁。
5. 酒店：进入酒店详情，测试预订订单。
6. 教练：进入教练详情，测试预约订单。
7. 社区：发布动态、点赞、进入详情评论、收藏、删除。
8. 我的：检查订单数量、收藏数量、我的订单、我的收藏。
