# SkiGo 滑雪一站式服务平台

基于微信小程序原生框架与微信云开发实现的滑雪服务类小程序，覆盖雪场浏览、雪票预订、酒店预订、装备购买/租赁、教练预约、滑雪社区、订单、收藏、个人中心和天气雪况展示等功能。

## 技术栈

- 前端：微信小程序原生 WXML / WXSS / JavaScript
- 后端：微信云开发云函数
- 数据库：微信云数据库
- 天气接口：Open-Meteo，通过云函数 `weatherService` 中转

## 目录结构

```text
滑雪小程序源码/
├─ app.js / app.json / app.wxss
├─ pages/                 小程序页面
├─ utils/                 本地工具与云函数调用封装
├─ images/                项目图片素材
└─ cloudfunctions/        微信云开发云函数
```

## 已实现功能

- 首页轮播、天气/雪况切换、功能入口、热门雪场、装备、教练和社区动态展示
- 雪场列表与雪场详情，支持收藏、订票、查看平台教练和雪场教练
- 装备商城与装备详情，支持购买、租赁和收藏
- 酒店列表、酒店详情与预订订单
- 教练列表、教练详情与预约订单
- 社区动态列表、发布、点赞、评论、删除和帖子收藏
- 我的页面、订单列表、收藏列表、个人资料编辑
- 云开发登录检测、订单/收藏/社区数据云端读写
- Open-Meteo 实时天气云函数代理，前端不保存接口凭证

## 云开发配置

当前开发环境 ID：

```text
cloud1-d6geemhftac318bc0
```

需要在微信开发者工具中上传并部署以下云函数：

- `login`
- `postService`
- `orderService`
- `favoriteService`
- `weatherService`

部署方式：右键云函数目录，选择“上传并部署：云端安装依赖”。

## 运行方式

1. 使用微信开发者工具导入本目录。
2. 确认 `project.config.json` 中 AppID 为目标小程序 AppID。
3. 确认云函数根目录 `cloudfunctions/` 已选择云环境。
4. 逐个上传并部署云函数。
5. 编译运行小程序，在“设置与帮助”中检测云端连接。

## 说明

项目保留本地缓存兜底逻辑：当云函数未部署或调用失败时，部分页面会使用本地示例数据，避免页面不可用。正式运行前应确认云函数已部署，并完成社区、订单、收藏和天气模块测试。
